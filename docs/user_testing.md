# User Testing — Yemen Opportunity Navigator 

## Test Overview

The final deployed application was tested by **4 real users** across both mobile and desktop devices.

- **2 users tested on mobile**
- **2 users tested on desktop**
- **2 users tested while authenticated**
- **2 users tested as guests**
- All four users tested search in **Arabic and English**
- All four users reviewed the main application sections

## Test Results

| User | Device | Access Mode | Arabic Search | English Search | Reviewed Main Sections | Rating |
|---|---|---|---|---|---|---:|
| User 1 | Mobile | Authenticated | Yes | Yes | Yes | 10/10 |
| User 2 | Mobile | Guest | Yes | Yes | Yes | 10/10 |
| User 3 | Desktop | Authenticated | Yes | Yes | Yes | 10/10 |
| User 4 | Desktop | Guest | Yes | Yes | Yes | 9.5/10 |

## Feedback Summary

Three users rated the application **10/10**.

One user rated the application **9.5/10** and suggested that a **dark color theme** could make the visual experience better.

No other usability issues were reported during these tests.

## Testing Conclusion

The four-user test covered:

- mobile and desktop access;
- authenticated and guest usage;
- Arabic search;
- English search;
- navigation across the main application sections.

The feedback indicates that the deployed application was usable across the tested devices and access modes. The only improvement suggestion received was an optional dark-theme preference.
